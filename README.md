## Selected Projects

### [Master Blaster Hub](https://github.com/jk377y/Master-Blaster-Hub)

Full-stack service management application built with **React, Java, Spring Boot, and MongoDB Atlas**.

The project includes JWT authentication, role-based access control, REST APIs, automated testing, Docker containerization, and a production AWS architecture using **ECS/Fargate, ECR, Application Load Balancer, S3, CloudFront, Route 53, and ACM**.

GitHub Actions workflows automated frontend and backend deployments.

**Focus:** Software Engineering • AWS • Docker • CI/CD • Full-Stack Development

---

### [ec2-monitoring-tool](https://github.com/jk377y/ec2-monitoring-tool)

A lightweight health dashboard for an **Amazon EC2 Linux** instance, deployed with a single command.

The main goal of this project is automation. Getting a tool like this onto a server normally means creating directories on the instance, copying files up one at a time, installing or checking dependencies, and starting each piece by hand. This project wraps all of that into one command, so nobody has to configure folders or upload files to the EC2 instance manually. You run bash `start.sh`, answer three prompts, and the launcher does the rest.

**Focus:** Bash • Linux/Windows/macOS • EC2 System Health Monitoring • Dashboard Display

---

### [AllClock](https://github.com/jk377y/AllClock)

Standalone Windows desktop application built with **Java 17 and JavaFX** for monitoring multiple time zones simultaneously.

Includes persistent user settings, window-state management, configurable time zones, and Windows packaging using Gradle and `jpackage`.

**Focus:** Java • JavaFX • Desktop Development • Application Packaging
